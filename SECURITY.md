# Security

Do not report credentials or sensitive data in a public issue.

This research repository should never contain API keys, solver license files,
private keys, access tokens, or machine-local credential stores. If such data
is found, contact the maintainer privately through the GitHub account that owns
the repository and identify the affected path and revision.

Historical experiment records may retain non-secret machine paths because
their bytes and provenance are immutable. Machine-local configuration files
remain ignored and are not part of a public release.
